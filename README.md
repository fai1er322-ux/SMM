# АктиБио Content Agent — Главный экран

---

## Как работаем

Каждая задача проходит через три этапа. Переход — только после твоего OK.

```
ЭТАП 1 — ИДЕЯ          →    ЭТАП 2 — ШТУРМ         →    ЭТАП 3 — СЦЕНАРИЙ
Трендовая идея              Варианты под бренд            Полный сценарий
Согласуешь с заказчиком     Выбираешь направление         Идёт в производство
```

---

## Что умею делать

### 🎬 ВЕРТИКАЛЬНЫЙ КОНТЕНТ (TikTok / Reels / ВК Клипы)

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Название идеи, тренд-основа, платформа, хронометраж, тип (лайф/польза/продукт) |
| **2 — Штурм** | 2–4 варианта реализации под АктиБио, сравнение углов |
| **3 — Сценарий** | Раскадровка по секундам, текст на экране, монтаж, реквизит, референс настроения |

---

### 📸 СТАТИЧНЫЕ ПОСТЫ (ВК / ТГ / Инст)

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Тема поста, тип контента, платформа, инфоповод |
| **2 — Штурм** | Несколько вариантов угла и визуального решения |
| **3 — Сценарий** | Финальный копирайт + описание визуала (композиция, цвет, текст на картинке) |

---

### 🎠 КАРУСЕЛЬ / КАРТОЧКИ

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Тема серии, количество карточек, платформа |
| **2 — Штурм** | Структурные варианты (польза / игра / список / история) |
| **3 — Сценарий** | Текст каждой карточки + описание визуала + первая карточка-хук |

---

### ✨ МОУШН-ШАБЛОНЫ (HTML/GSAP)

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Концепция анимации, формат, тренд-основа |
| **2 — Штурм** | Варианты визуального решения и анимационного стиля |
| **3 — Сценарий** | Готовый HTML-файл с анимацией, открывается в браузере |

---

### 📋 ТЗ ДЛЯ КРЕАТОРОВ

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Концепция ролика, формат интеграции (UGC / нативная / прямая) |
| **2 — Штурм** | Несколько сценарных направлений на выбор |
| **3 — Сценарий** | Полный бриф: кастинг, локация, реквизит, раскадровка, требования к съёмке |

---

### 📅 КОНТЕНТ-ПЛАН

| Этап | Что получаешь |
|------|--------------|
| **1 — Идея** | Инфоповоды и темы периода |
| **2 — Штурм** | Распределение по форматам и платформам |
| **3 — Сценарий** | Готовый план с датами, форматами, типами, статусами |

---

### 🔍 МОНИТОРИНГ ТРЕНДОВ

| Что делаю | Результат |
|-----------|----------|
| Ищу тренды в TikTok / Reels / ВК по теме недели | 5–7 трендов с описанием |
| Фильтрую через призму бренда АктиБио | Оставляю только подходящие |
| Предлагаю адаптацию | Идеи для Этапа 1 |

> Запрос: `Найди тренды` → сразу получаешь готовые идеи для согласования

---

## Форматы на выходе

| Тип файла | Где лежит |
|-----------|----------|
| Идеи (md) | `content/posts/` |
| Раскадровки (md) | `content/scenarios/` |
| ТЗ для креаторов (md) | `content/briefs/` |
| Моушн-шаблоны (html) | `content/motions/` |
| Контент-планы (md) | `plans/` |

---

## Быстрые команды

| Что сказать | Что сделаю |
|-------------|-----------|
| `Найди тренды` | Мониторинг → 5 идей для Этапа 1 |
| `Идея: [тема]` | Этап 1 — короткая идея на согласование |
| `Штурм: [идея]` | Этап 2 — варианты реализации |
| `Сценарий: [вариант]` | Этап 3 — полный сценарий |
| `Пост [тип] для [платформы]` | Все 3 этапа или начинаем с 1 |
| `Контент-план на [период]` | Полный план по этапам |
| `ТЗ для креатора: [идея]` | Бриф для съёмочной группы |
| `Моушн: [текст/идея]` | HTML-анимация в фирменном стиле |
